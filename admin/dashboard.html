Acesso & Ajuda

Trocar usuário/senha

O login jsmunize / jojo7811 funciona por segurança básica do Cloudflare. Para trocar (recomendado), acesse no Cloudflare:

  1. Workers & Pages → seu site → Settings → Environment variables
  2. Adicione ADMIN_USER e ADMIN_PASS com seus novos valores

Dica de segurança: use uma senha forte e mantenha o repositório do GitHub privado. As informações do site não ficam expostas no código — somente você tem acesso.

Onde os dados são salvos?

Em um banco Cloudflare KV (binding SETTINGS). Se aparecer erro "binding KV não configurado", veja o README do projeto: é preciso criar a KV e vincular em Settings → Bindings. Enquanto não configurado, o site usa os valores padrão.

Feed do Instagram

Depende das variáveis INSTAGRAM_TOKEN e INSTAGRAM_USER_ID. Veja o README para o passo a passo.
